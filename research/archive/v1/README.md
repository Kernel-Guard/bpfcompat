# Pilot v1 scholarly archive

This directory contains the frozen policy and compact lock used to regenerate
the BPFCompat pilot-v1 scholarly data payload.

- `archive-plan.json` freezes the three source Actions artifacts and the
  redistribution policy applied to materialized inputs.
- `archive-lock.json` is generated from the complete release-shaped bundle and
  is committed only after the archive builder passes its fail-closed checks.
- The full `archive-manifest.json`, deterministic payload ZIP, and
  `RELEASE-CHECKSUMS.txt` are generated by
  `scripts/research/archive-v1.py` and uploaded by the
  `research-archive-v1` workflow.

The full manifest contains one row per payload file. It is intentionally not
duplicated into Git history; its SHA-256, file count, total bytes, payload ZIP
identity, source artifact identities, and excluded rebuildable identities are
bound by the committed archive lock.

The cilium/ebpf project-loader binary and Falco `scap-open` binary are excluded
from the payload by default. Their hashes, source revisions, validation-contract
identities, and retained notice paths remain represented in the generated
manifest and lock.
