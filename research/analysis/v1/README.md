# Pilot v1 Analysis

scripts/research/analyze-study-v1.py deterministically regenerates the
descriptive RQ1–RQ4 tables under generated from research/data/v1.

This is not a claim of preregistration. Corpus case roles and denominator
policy were frozen before collection. The pilot is selected and x86_64-only,
so rates are descriptive within this corpus.

RQ3 reports paired verdict agreement only because the Cilium-derived
contracts differ (load+attach versus load-only). RQ4 can show cross-vendor
variation but cannot estimate patch-level longitudinal change from one exact
environment per logical profile.
