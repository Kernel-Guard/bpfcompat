# Production Technical Track

This track defines technical production readiness for controlled deployments.

## Gate Command

```bash
make production-tech-check
```

Outputs:

- `evidence/production-tech/production-tech-check-<timestamp>.md`
- logs in `evidence/production-tech/logs-<timestamp>/`

## Included Controls

1. Go unit tests and `go vet`
2. hostile artifact and configuration checks
3. release metadata and generated-document consistency
4. production support, SLO, incident, schema, upgrade, and hardening documents
5. protected release review and graduation evidence defined in
   `docs/production-release-process.md`
6. separate release-candidate VM and supported weekly campaign evidence
