## Narrow corrections

The 725 importer now selects only the authoritative RSA key's SHA256 encoding,
checks its exact bytes before import and retains RPM signature and DNF local
package GPG checks. This avoids unsupported unrelated SHA1/V6 keys. Transport
deadlines/retries are bounded and terminal failures stay infrastructure errors.
Offline tests reject altered key bytes before any privileged command. Real
acceptance still requires exact kernel identity, load/attach and negative tests.

Release review found and corrected evidence upload paths (including incomplete
runs), executable permissions lost by artifact transfer, missing Action `gh`
authentication, loose promotion workflow identity matching, missing native SBOM
inputs, missing elapsed-time checks for timed canaries and missing provenance
invocation binding for producing observations. Local fixtures are not OIDC proof.
